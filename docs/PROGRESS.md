### Діагностика й проблема з Delta 3
- Симптом: статус «Підключено», Delta 2 Max працює, Delta 3 офлайн (у телефоні онлайн). Протокол Delta 3, ClientId і запит стану збігаються з Android байт у байт; розбір Delta 3 проходить тести на кадрах із Android-тестів
- [x] `OnMessage`: виняток у `Parse` більше не губить повідомлення — станція вважається онлайн за будь-який трафік (як в Android), а збій іде в журнал з hex-префіксом кадру
- [x] `DiagLog` (`diag.log`, 256 КБ з обрізанням): стан з'єднання, список підписаних станцій, «перші дані від …» для кожної станції, збої розбору, невдалі команди, синхронізація, падіння. Налаштування → Діагностика: відкрити / копіювати / очистити
- [ ] **Надіслати журнал після запуску з Delta 3** — з нього видно, чи приходять від неї кадри взагалі
